# FinTech Wallet & Fraud Detection System

A full-stack digital wallet application developed as an Industrial Training (ITR) project.

## Technology Stack

### Backend
- Python
- Django
- Django REST Framework
- PostgreSQL
- JWT Authentication
- django-cors-headers

### Frontend
- React
- JavaScript
- Axios
- Bootstrap
- CSS

## Main Features

- User registration and login
- JWT-based authentication
- User profile management
- Digital wallet
- Add money
- Withdraw money
- Money transfer between users
- Transaction history
- Pending and failed transactions
- Admin dashboard
- User management
- Fraud transaction review
- Fraud alerts
- Analytics dashboard
- Transaction charts and statistics
- Wallet activity and financial summary
